- 2026-10-27 · **Change 03 step 2: content Sheet.** `src/content.config.ts` loaders now read each YAML file, apply the Sheet (`src/lib/overrides.ts`, unit-tested) and then validate, so a Sheet value that breaks a schema fails the build like a YAML typo would, while rows the Sheet can't use become warnings and the YAML stands. Tabs: `strings` (any existing copy field by dotted key, never links, ids, slugs, photos, contact details or brand identity), `offers`, `faqs`, `industries`, `testimonials`, `flags`. Source is the Sheet's gviz CSV by tab name (`SHEET_CONTENT_ID`), per-tab `SHEET_CONTENT_URL_<TAB>` overrides allowed; fallback is `src/content/snapshot/*.json` written by `npm run sheet:sync` (nightly GitHub Action `sheet-sync.yml`, gated on the `SHEET_SYNC_BRANCH` variable). `/content-seed.json` lists every editable key with its YAML default so the Sheet's Apps Script (`docs/google-sheet-content/Code.gs`) can create and refresh the tabs itself; the menu also posts to a Cloudflare deploy hook to publish. FAQs moved from `offers.yaml` to `faqs.yaml`, keyed by page, so the Sheet can replace a page's list. The `home`/`offers` `faq_heading` keys were replaced by `faqs.heading`.
